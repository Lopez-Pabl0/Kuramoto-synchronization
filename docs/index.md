# Documentation

Study of the synchronization phenomenon through the Kuramoto model. The transition
between incoherent and synchronized states is investigated by comparing theoretical
predictions with numerical simulations. The main objective is to characterize this
transition and to understand the role of the natural frequency distribution.

All documents follow the same structure:

1. **Motivation**: what is to be studied and what is expected to be observed.
2. **Theory**: the physics and the analytical predictions.
3. **Implementation**: how the code addresses the problem and with which parameters.
4. **Results**: the figures obtained and their comparison with theory.
5. **How to reproduce**: the command and its approximate cost.

## Conclusions

- **Reliability of the simulations.** The study of the numerical parameters
  establishes a simulation framework that meets two goals: a satisfactory
  representation of the model and an acceptable computational cost. The simulations
  reproduce the analytical predictions with high accuracy: $e^{-\Delta t}$,
  $|J_0(t)|$, $r_\text{sat}$ and the Lorentzian $r(K)$.
- **Transition between states.** The study of the order parameter $r$ provides a
  deep understanding of synchronization and yields the conditions required for the
  transition from incoherent to synchronized states, and vice versa.
- **Role of the frequency distribution.** Studying the same problem with different
  distributions shows that, given basic conditions of the system, the model accounts
  for phenomena as different as an analytical evolution of $r(K)$ (Lorentzian) and a
  hysteresis phenomenon (arcsin(−1,1)).

Starting from great mathematical simplicity, the Kuramoto model is able to explain a
phenomenon that is, in principle, puzzling, synchronization, which seems to defy the
tendency of systems towards disorder.

## Figures

All figures are stored in [`img/`](img/). The result figures are generated by the

number of the document in which it appears.

## Notation

| Symbol | Meaning |
|---|---|
| $N$ | Number of oscillators |
| $\theta_i(t)$ | Phase of oscillator $i$ |
| $\omega_i$ | Natural frequency of oscillator $i$ |
| $g(\omega)$ | Probability density of the natural frequencies |
| $\rho(\theta,\omega,t)$ | Phase density for a given frequency ($N\to\infty$ limit) |
| $\Delta$ | Width of the Lorentzian distribution (`width` in the code) |
| $K$ | Coupling constant (`k` in the code) |
| $K_c$ | Critical coupling |
| $K_s$ | Synchronization threshold of the backward branch (hysteresis) |
| $r,\ \Psi$ | Order parameters: phase coherence and mean phase |
| $r_\text{sat}$ | Saturation value of $r$ in the stationary regime for a fixed $K$ |
| $J_0(t)$ | Bessel function of the first kind of order zero |
| $dt,\ T$ | Time step and total evolution time |
| `t_discard` | Time from which $r$ is averaged (onset of the stationary regime) |
